SOBRE EL PROYECTO

Una herramienta para planificar mejor

DevTasks forma parte de un proyecto académico orientado al desarrollo de aplicaciones web y a la gestión de información.

El sistema utiliza Flask para el servidor y SQLite para la persistencia de usuarios. Incluye funcionalidades de registro, inicio de sesión y consulta de tareas.

  • ✓ API desarrollada con Flask
  • ✓ Persistencia con SQLite
  • ✓ Protección de contraseñas
  • ✓ Cliente de consola en Python
